# tfm-ai
TFM de Desarrollo de IA Generativa

Este proyecto consiste en una aplicación de inteligencia artificial generativa orientada al análisis del sector del turismo, presentada a través de una interfaz web interactiva.

# Objetivo
Proporcionar insights y análisis inteligentes sobre datos del sector turístico, apoyando la toma de decisiones mediante modelos de IA generativa.

# Funcionalidades
- Análisis de datos del sector turismo
- Generación automática de informes y conclusiones
- Visualización de resultados en una interfaz web
- Interacción sencilla para el usuario

# Tecnologías utilizadas
- Análisis de datos
- Inteligencia Artificial Generativa
- Interfaz Web


# Uso
1. Accede a la interfaz web
2. Consulta los datos turísticos
3. Visualiza los análisis generados por la IA
